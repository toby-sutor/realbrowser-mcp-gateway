Install guide

BASE-MAIN This guide walks through installing the toolkit on a fresh machine. First read the requirements page, then follow the first step. If something fails, consult the troubleshooting section or the API reference.

The installer is self-contained and needs no network access after the download finishes. You can also read the PDF edition if you prefer reading offline, and the requirements page is linked twice on purpose to test de-duplication.

Verifying the install

Run the self-test and compare the output with the table in the verification step. A clean run prints a green summary and exits with status zero.
