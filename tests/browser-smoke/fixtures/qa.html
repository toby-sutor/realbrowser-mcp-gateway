How do I load a script only after the page has rendered?

QA-VOTES 42

QAQUESTION-MAIN I have a page that includes a tracking snippet with <script src="tracker.js"></script> in the head, and it delays the first paint by several hundred milliseconds. The page also embeds a video in an <iframe> and carries a small <style> block. This is the whole document:

<!doctype html>
<html>
<head>
  <!-- the tracker -->
  <style>body { margin: 0 }</style>
  <script src="tracker.js"></script>
</head>
<body>
  <iframe src="https://video.example.org/embed/42" width="560" height="315"></iframe>
</body>
</html>

What is the right way to keep the tracker from blocking rendering, without moving it to the end of the body by hand on every page of the site?

QAANSWER-ONE Add the defer attribute. A <script defer> is fetched in parallel and runs after the document has been parsed, in order, so nothing else has to move. The frame can wait as well:

<script defer src="tracker.js"></script>
<iframe loading="lazy" src="https://video.example.org/embed/42"></iframe>

How the two attributes differ:

AttributeFetchRuns
noneblocks parsingat once
asyncin parallelas soon as it arrives
deferin parallelafter parsing, in order

QAANSWER-TWO If you cannot change the markup, insert the element from JavaScript once the page has loaded. Note that the string "<script>" below is only text:

window.addEventListener("load", () => {
  const s = document.createElement("script");
  s.src = "tracker.js";
  s.async = true;
  document.head.appendChild(s);
  if (a < b && c > d) console.log("<script> injected");
});

This costs one more round trip than defer, so prefer the attribute where you can.
